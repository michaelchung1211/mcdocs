How It Works · 站台架構

這個站怎麼運作

整個站就是一堆靜態 HTML 檔，由 GitHub Pages 直接服務。沒有打包步驟，也沒有後端。

  • 首頁 index.html 透過 GitHub API 自動列出 pages/ 裡的所有 .html。
  • 每一篇主題是一個 .html 檔，放在 pages/。
  • 共用樣式在 assets/style.css。色票和元件規格寫在 style.md。
Note · 補充

標題從每個檔案的 <title> 抓；副標從 <meta name="description"> 抓。底線開頭的檔名（例如 _template.html）會被自動跳過。

Add a Page · 新增一篇

新增一篇主題

兩步：複製範本、填內容、推上去。首頁會自己列出來。

i

複製範本

把 _template.html 複製成 pages/<slug>.html，例如 pages/claims.html。slug 用英文小寫，不要有空白。

ii

填入內容

改 <title>、<meta name="description">、eyebrow、<h1>、lead 和各個 section。Commit、push 後首頁會自動抓到。

FAQ 摺疊區 Details

怎麼讓某一篇暫時不要顯示？

把檔名前面加底線，例如 _draft-claims.html。底線開頭的檔案不會出現在首頁清單上。

標題不想用 <title> 的內容怎麼辦？

加一行 <meta name="docs-title" content="領地系統">，這會優先被首頁採用。
