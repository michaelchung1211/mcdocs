Updated · 2026-06-04
01 · How It Works · 站台架構

這個站怎麼運作

整個站只是 docs/ 資料夾裡的一堆靜態 HTML 檔。GitHub Pages 直接服務這個資料夾，沒有打包、沒有後端。

  • 首頁 index.html 讀取 manifest.json，把每一篇主題列出來。
  • 每一篇主題是一個 .html 檔，放在 docs/ 最上層。
  • 共用的樣式在 assets/style.css，字體從 Google Fonts 載入。
Note · 補充

路徑都用相對路徑（./assets/...），所以無論 GitHub Pages 的網址前綴是什麼，連結都會正確。

02 · Add a Page · 新增一篇

新增一篇主題

三個步驟：複製範本、填內容、登錄到 manifest。

i

複製範本

把 _template.html 複製成 <slug>.html，例如 claims.html。slug 用英文小寫，不要有空白。

ii

填入內容

編輯 <title>、eyebrow、<h1>、lead 段落和各個 section。範本裡已經放好常用元件（callout、step、指令清單、FAQ）。

iii

登錄到 manifest.json

打開 manifest.json，在 topics 陣列加一筆：

{
  "slug":    "claims",
  "title":   "領地系統",
  "summary": "保護你的建築不被其他玩家修改。",
  "path":    "claims.html",
  "updated": "2026-06-04"
}

Commit、push，首頁下次重新整理就會列出來。
